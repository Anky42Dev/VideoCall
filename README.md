# Face to Face

Видеозвонок один на один на WebRTC. WebSocket используется только для обмена `offer`, `answer` и ICE-кандидатами; видео и звук передаются напрямую между браузерами.

## Локальный запуск

Доступ к камере работает только в безопасном контексте (`https` или `localhost`), поэтому откройте проект через локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в двух окнах браузера и разрешите доступ к камере и микрофону.

## GitHub Pages

Публикация выполняется автоматически через GitHub Actions после каждого push в ветку `main`. Workflow также можно запустить вручную на вкладке **Actions → Deploy to GitHub Pages → Run workflow**.

Сайт доступен по адресу `https://anky42dev.github.io/VideoCall/`.
